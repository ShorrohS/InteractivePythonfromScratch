# ⚙️ Phase 00 — Development Environment Setup

> **Goal:** Set up a professional Python development environment from scratch.

---

## What You Will Accomplish

By the end of this phase, you will have:

- ✅ Python installed and verified on your machine
- ✅ VS Code configured with Python extensions
- ✅ Full terminal/command-line competency
- ✅ Virtual environments working
- ✅ Git set up with your first commit
- ✅ A properly structured Python project folder
