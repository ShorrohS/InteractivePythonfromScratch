# 🐍 Phase 01 — Python Fundamentals

> **Goal:** Learn the core building blocks of Python — the concepts used in every single program.

---

## What You Will Learn

By the end of this phase, you will:
- Write Python programs that take input and produce output
- Work with all fundamental data types
- Perform calculations and string operations
- Build 5 real mini applications

---

## Lessons

| # | Lesson | Concept | Time |
|---|--------|---------|------|
| 01 | [Hello World](concepts/lesson-01-hello-world.md) | print(), comments | 20 min |
| 02 | [Variables](concepts/lesson-02-variables.md) | Variables, assignment, naming | 30 min |
| 03 | [Data Types](concepts/lesson-03-data-types.md) | int, float, str, bool | 45 min |
| 04 | [Input & Output](concepts/lesson-04-input-output.md) | input(), type conversion | 30 min |
| 05 | [Operators](concepts/lesson-05-operators.md) | Arithmetic, comparison, logical | 45 min |
| 06 | [Strings](concepts/lesson-06-strings.md) | String methods, f-strings | 60 min |
| 07 | [Numbers](concepts/lesson-07-numbers.md) | Math operations, math module | 30 min |
| 08 | [Boolean Logic](concepts/lesson-08-boolean-logic.md) | True/False, and/or/not | 30 min |
