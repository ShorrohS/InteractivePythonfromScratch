# 🔀 Phase 02 — Control Flow

> **Goal:** Make programs that make decisions and repeat actions.

---

## What You Will Learn

Control flow is how programs decide WHAT to do and HOW MANY TIMES to do it. This phase covers the most-used logic structures in all of Python.
