**Q1.** Write a function `greet(name)` that returns `"Hello, [name]!"`.
Call it 3 times with different names.

---

**Q2.** Write a function `add(a, b)` that returns the sum.
Write `subtract(a, b)`, `multiply(a, b)`, `divide(a, b)`.
For divide, return `None` if b is zero.

---

**Q3.** Write a function `is_even(n)` that returns `True` if n is even.
Write `is_odd(n)` that uses `is_even`.

---

**Q4.** Write a function `celsius_to_fahrenheit(c)` and `fahrenheit_to_celsius(f)`.
Test both ways with 100°C / 212°F.

---

**Q5.** Write a function `area_of_rectangle(length, width)` and
`perimeter_of_rectangle(length, width)`.

---

**Q6.** Write `find_max(a, b, c)` that returns the largest of 3 numbers without using `max()`.

**Q7.** Write `count_vowels(text)` that returns the number of vowels in a string.

**Q8.** Write `repeat_string(text, n=2)` that returns the string repeated n times.

**Q9.** What is the output?
```python
def mystery(x, y=5):
    return x * y

print(mystery(3))
print(mystery(3, 10))
print(mystery(y=2, x=4))
```
