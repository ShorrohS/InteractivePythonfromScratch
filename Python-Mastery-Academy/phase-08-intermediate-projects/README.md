## Build Order

Build them in order — each is slightly more complex than the last.

```
To-Do App → Notes App → Expense Manager → Password Manager →
Contact Manager → Employee Payroll → Library System
```

---

## What Each Project Demonstrates

### To-Do App
```
Features: add, list, complete, delete tasks
Data: JSON file persistence
OOP: Task class, TodoApp class
Input: Validation
```

### Contact Manager
```
Features: add, search, update, delete contacts
Data: JSON file
OOP: Contact class, ContactBook class
Search: by name, phone, email
```

### Employee Payroll
```
Features: Employee management + monthly payroll generation
Data: CSV export
OOP: Employee hierarchy (Full-time, Part-time, Contract)
Reports: Payroll summary, department totals
```

### Library System
```
Features: Books, Members, Borrowing/Returns
Data: JSON persistence
OOP: Book, Member, Library classes + inheritance
Search: by title, author, ISBN
```
