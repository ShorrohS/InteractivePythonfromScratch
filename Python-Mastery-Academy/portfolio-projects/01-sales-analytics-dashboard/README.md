# Sales Analytics Dashboard — Portfolio Project

> A complete sales analysis system with charts and Excel reports.

---

## Project Overview

This project demonstrates data analysis skills using real-world sales data. It processes CSV data, generates insights, creates visualizations, and exports Excel reports.

---

## Features

- ✅ Import and clean sales data from CSV
- ✅ Revenue by product, region, and time period
- ✅ Sales rep performance leaderboard
- ✅ Year-over-year comparison
- ✅ Interactive charts (bar, line, pie)
- ✅ Multi-sheet Excel export
- ✅ KPI summary dashboard

---

## Technologies

| Technology | Purpose |
|-----------|---------|
| pandas | Data manipulation |
| matplotlib | Charts and visualization |
| seaborn | Enhanced visuals |
| openpyxl | Excel export |
| numpy | Numerical operations |

---

## Quick Start

```bash
pip install pandas matplotlib seaborn openpyxl numpy
python main.py
```

Generates:
- `sales_dashboard.png` — Visual dashboard
- `sales_report.xlsx` — Multi-sheet Excel report
