## 💡 What is Python Mastery Academy?

**Python Mastery Academy** is an open-source, self-paced mastery curriculum structured as a modern code repository and an interactive, dark-themed web platform.

Unlike fragmented tutorials or video series, this academy is designed around **active, project-based engineering**:
- 🧠 **Mental Models & Visual Analogies:** Understand how Python interacts with memory, CPU, storage, and the operating system.
- ⚡ **Zero-Friction Web Viewer:** Read lessons, inspect code, and track progress on any device via GitHub Pages.
- 🧪 **Multi-Tiered Practice:** Beginner, Intermediate, and Advanced exercises with official solution sets.
- 🐛 **Debugging Challenges:** Learn to diagnose stack traces, edge cases, and runtime bugs.
- 🛠️ **25+ Guided & Portfolio Applications:** Build real CLI utilities, REST APIs, GUI applications, database backends, and full-stack software.
- 🎓 **Production Capstone:** Complete with unit test suites, `.env` management, architecture documentation, and deployment guides.

## 🗺️ 21-Phase Curriculum Roadmap

The curriculum is divided into four progressive tracks:

```
Track 1: Foundations ──► Track 2: Core Engineering ──► Track 3: Intermediate ──► Track 4: Advanced & Production
```

### 🟢 Track 1: Foundations (Phases 00 – 03)
* **[Phase 00 — Environment Setup](https://shorrohs.github.io/InteractivePythonfromScratch/lesson.html?path=Python-Mastery-Academy/phase-00-environment/README.md):** Python installation, VS Code mastery, terminal fluency, virtual environments (`venv`), and Git version control.
* **[Phase 01 — Fundamentals](https://shorrohs.github.io/InteractivePythonfromScratch/lesson.html?path=Python-Mastery-Academy/phase-01-fundamentals/README.md):** Variables, memory binding, data types, I/O, operators, strings, numbers, and boolean logic.
* **[Phase 02 — Control Flow](https://shorrohs.github.io/InteractivePythonfromScratch/lesson.html?path=Python-Mastery-Academy/phase-02-control-flow/README.md):** `if/elif/else`, modern `match-case`, `while` loops, `for` loops, nested loops, `break`, and `continue`.
* **[Phase 03 — Collections & Data Structures](https://shorrohs.github.io/InteractivePythonfromScratch/lesson.html?path=Python-Mastery-Academy/phase-03-collections/README.md):** Lists, tuples, dictionaries, sets, comprehensions, and nested data modeling.

### 🔵 Track 2: Core Engineering (Phases 04 – 07)
* **[Phase 04 — Functions & Modularity](https://shorrohs.github.io/InteractivePythonfromScratch/lesson.html?path=Python-Mastery-Academy/phase-04-functions/README.md):** Parameters, return semantics, default arguments, `*args` / `**kwargs`, LEGB scope, recursion, and lambda expressions.
* **[Phase 05 — File Handling](https://shorrohs.github.io/InteractivePythonfromScratch/lesson.html?path=Python-Mastery-Academy/phase-05-file-handling/README.md):** Reading/writing text files, CSV manipulation, structured JSON parsing, and modern `pathlib`.
* **[Phase 06 — Error Handling & Defensive Coding](https://shorrohs.github.io/InteractivePythonfromScratch/lesson.html?path=Python-Mastery-Academy/phase-06-error-handling/README.md):** `try/except/else/finally`, custom exception hierarchies, defensive programming, and assertions.
* **[Phase 07 — Object-Oriented Programming (OOP)](https://shorrohs.github.io/InteractivePythonfromScratch/lesson.html?path=Python-Mastery-Academy/phase-07-oop/README.md):** Classes, instances, encapsulation, inheritance, polymorphism, abstraction, and dunder (`__magic__`) methods.

### 🟡 Track 3: Intermediate Mastery (Phases 08 – 14)
* **[Phase 08 — Intermediate Projects](https://shorrohs.github.io/InteractivePythonfromScratch/lesson.html?path=Python-Mastery-Academy/phase-08-intermediate-projects/README.md):** 7 real-world CLI projects (Notes App, Password Manager, Expense Manager, Library System, Contact Manager, Todo App, Employee Payroll).
* **[Phase 09 — Databases & SQL](https://shorrohs.github.io/InteractivePythonfromScratch/lesson.html?path=Python-Mastery-Academy/phase-09-databases/README.md):** Relational databases, SQL DDL/DML, Python `sqlite3`, migrations, and query optimization.
* **[Phase 10 — Web Scraping](https://shorrohs.github.io/InteractivePythonfromScratch/lesson.html?path=Python-Mastery-Academy/phase-10-web-scraping/README.md):** HTTP semantics, `requests`, BeautifulSoup parsing, selectors, and news scrapers.
* **[Phase 11 — Working with APIs](https://shorrohs.github.io/InteractivePythonfromScratch/lesson.html?path=Python-Mastery-Academy/phase-11-apis/README.md):** REST APIs, JSON serialization, API authentication, currency converters, and live weather dashboards.
* **[Phase 12 — Task & System Automation](https://shorrohs.github.io/InteractivePythonfromScratch/lesson.html?path=Python-Mastery-Academy/phase-12-automation/README.md):** Filesystem automation, batch file organization, scripting, and system tasks.
* **[Phase 13 — Data Analysis Fundamentals](https://shorrohs.github.io/InteractivePythonfromScratch/lesson.html?path=Python-Mastery-Academy/phase-13-data-analysis/README.md):** Introduction to NumPy, Pandas data structures, series, dataframes, and sales analytics reporting.
* **[Phase 14 — Automated Testing & TDD](https://shorrohs.github.io/InteractivePythonfromScratch/lesson.html?path=Python-Mastery-Academy/phase-14-testing/README.md):** Unit testing with `pytest`, fixtures, assertions, API mocking, test coverage, and test-driven development.

### 🟣 Track 4: Advanced & Production Engineering (Phases 15 – 20)
* **[Phase 15 — GUI Development](https://shorrohs.github.io/InteractivePythonfromScratch/lesson.html?path=Python-Mastery-Academy/phase-15-gui/README.md):** Desktop applications with `tkinter`, layout geometry, event-driven programming, and full CRUD GUI applications.
* **[Phase 16 — Web Development](https://shorrohs.github.io/InteractivePythonfromScratch/lesson.html?path=Python-Mastery-Academy/phase-16-web-development/README.md):** Backend web development using Flask and FastAPI, routes, request models, and full REST services.
* **[Phase 17 — Advanced Python](https://shorrohs.github.io/InteractivePythonfromScratch/lesson.html?path=Python-Mastery-Academy/phase-17-advanced-python/README.md):** Custom decorators, generators, class & function-based context managers (`@contextmanager`), `@dataclass`, and asynchronous Python (`asyncio`).
* **[Phase 18 — Real-World Business Systems](https://shorrohs.github.io/InteractivePythonfromScratch/lesson.html?path=Python-Mastery-Academy/phase-18-business-projects/README.md):** Enterprise applications including Employee Management Systems, Expense Trackers, and Ticket Management Platforms with SLA tracking.
* **[Phase 19 — Software Engineering Principles](https://shorrohs.github.io/InteractivePythonfromScratch/lesson.html?path=Python-Mastery-Academy/phase-19-software-engineering/README.md):** SOLID principles, design patterns (Factory, Singleton, Observer, Repository, Strategy), production logging, and project architecture.
* **[Phase 20 — Production Capstone Application](https://shorrohs.github.io/InteractivePythonfromScratch/lesson.html?path=Python-Mastery-Academy/phase-20-capstone/README.md):** End-to-end production software with comprehensive test suites (20+ tests), architecture specifications, environment configurations, and deployment guidelines.

## 🚀 Getting Started

### Option 1: Study in the Browser (Recommended)
No installation or local setup required. Simply navigate to:
👉 **[https://shorrohs.github.io/InteractivePythonfromScratch/](https://shorrohs.github.io/InteractivePythonfromScratch/)**

### Option 2: Clone & Run Locally
To run code locally, solve exercises, and execute tests:

```bash
# 1. Clone the repository
git clone https://github.com/ShorrohS/InteractivePythonfromScratch.git
cd InteractivePythonfromScratch

# 2. Check Python installation (Python 3.10+ recommended)
python --version

# 3. Explore and run any demo script
python "Python-Mastery-Academy/phase-00-environment/demos/demo-01-hello-world.py"

# 4. Run the Capstone test suite
python "Python-Mastery-Academy/phase-20-capstone/tests/test_main.py"
```
